# Bitrix Demo Catalog

Демонстрационный модуль для 1С-Битрикс,
разработанный с использованием D7 API и ORM.

## Возможности

- создание таблицы товаров;
- ORM-модель;
- CRUD;
- административный интерфейс;
- обработчики событий;
- настройки модуля;
- логирование.

## Technologies

- PHP 8.x
- 1C-Bitrix
- Bitrix D7
- ORM
- MySQL
- Git
